14.1. Khung nghiên cứu
----------------------
- Mô hình A (cấu trúc/kinh tế lượng): giải thích GDP_Growth bằng các biến vĩ mô chính thức.
- Mô hình B (forecast/nowcast): kiểm tra giá trị bổ sung của sentiment trên overlap thực 2019Q3-2025Q1.

14.2. Công thức mô hình
-----------------------
Model A - OLS/HAC (annual):
GDP_Growth_t = beta0 + beta1*Inflation_t + beta2*Interest_Rate_t + beta3*FDI_pct_GDP_t
               + beta4*Investment_pct_GDP_t + beta5*Export_pct_GDP_t
               + beta6*Unemployment_Rate_t + beta7*Gov_Spending_pct_GDP_t + e_t

Model B - Dynamic regression on actual overlap:
GDP_Growth_t = alpha0 + alpha1*GDP_Growth_{t-1} + alpha2*Inflation_t + alpha3*Interest_Rate_t
               + alpha4*Net_Sentiment_t + alpha5*Avg_Sentiment_t + u_t

Forecast model used in section 15:
y_t = c + sum(phi_i * y_{t-i}) + sum(theta_j * eps_{t-j}) + gamma'X_t + eps_t
with X_t = [Inflation_t, Interest_Rate_t] for macro SARIMAX.

Where estimated coefficients will appear in the output:
- Model A beta estimates: Section 17.1 (Annual OLS/HAC coefficient table + estimated equation)
- Model B alpha estimates: Section 20.1 (dynamic-regression coefficient tables + estimated equations)
- Final forecasting coefficients: Section 15.4 (final SARIMAX coefficient table + estimated equation)

19.6. Interpretation for the report
-----------------------------------
Suggested text for the project:
- Deep learning was implemented as an additional forecasting layer, not as a replacement for the interpretable econometric core.
- The LSTM/GRU block uses quarterly windows (lookback = 4) and a strict time split ending at 2022Q4 for training.
- A naive last-observation benchmark is reported to avoid overstating deep-learning performance on a small sample.
- If the best deep-learning model does not beat the naive/SARIMAX baseline, keep it as a robustness or innovation appendix.
- If macro+sentiment LSTM beats macro-only LSTM, the result can be framed as evidence that sentiment adds nonlinear nowcasting value on the short overlap sample.
- If it does not beat the benchmark, conclude that the current sample is too short/noisy for deep learning to dominate classical time-series models.

19.7. Extra deep-learning extensions you can mention
----------------------------------------------------
Possible next extensions for the final report or future work:
1) Bidirectional/attention LSTM only when the dataset becomes much longer.
2) Multi-horizon forecasting (predict 1Q, 2Q, 4Q ahead) instead of one-step ahead.
3) Hyperparameter tuning over lookback, hidden units, dropout, and learning rate.
4) Add policy/event dummy variables (Covid shock, tightening cycle, trade shock) into the input tensor.
5) Use rolling-origin backtesting for the deep-learning models exactly like the classical forecasting block.

20.5. Final recommendation
--------------------------
1) NÊN TÁCH thành 2 mô hình nghiên cứu dưới cùng một khung đề tài.
   - Mô hình A (cấu trúc/kinh tế lượng): annual OLS/HAC để giải thích GDP growth bằng biến vĩ mô chính thức.
   - Mô hình B (forecast/nowcast): quarterly SARIMAX làm baseline dự báo; sentiment chỉ dùng như mô hình phụ trợ trên overlap thực.
2) Không nên gộp thành một mô hình duy nhất vì:
   - coverage mismatch giữa macro dài hạn và sentiment ngắn hạn;
   - model_ready có leakage/backfill sentiment trước 2019Q3;
   - sentiment cải thiện in-sample nhưng không cải thiện out-of-sample;
   - có structural break mạnh quanh 2021-2022.
3) Kết luận lựa chọn mô hình:
   - Model A main choice: Annual OLS/HAC (explainability / structural interpretation)
   - Model B main choice: Quarterly SARIMAX on gdp_qoq_pct_recalc (forecasting)
   - Sentiment model: supplementary evidence only, not the single integrated final model
